# tabby street designer

Downloads for the invite-only alpha of tabby street designer, a Rhino 8 plug-in for street design by [EvolvArk](https://evolvark.com/labs/tabby/), Copenhagen.

The source code is private. This repository only holds release files.

## Download

All versions: [Releases](https://github.com/evolvark-labs/tabby-releases/releases)

Windows, Rhino 8. A licence key is needed; it comes with your invitation.

## Install

1. Download the zip. Right-click → Properties → tick **Unblock** → OK.
2. Unzip to a permanent folder. Keep all files together.
3. Drag `Tabby.rhp` into Rhino 8.
4. Run `TabbyLicence` and paste your key.

The full guide is in the zip: `tabby-alpha-guide.pdf`.
